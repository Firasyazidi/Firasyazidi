## 🚀 Featured Project — [AI Grocery Lab](https://github.com/Firasyazidi/ai-grocery-lab)

[![AI Grocery Lab 3D Supermarket Preview](https://firasyazidi.github.io/assets/og-ai-grocery-lab.png)](https://firasyazidi.github.io/demos/ai-grocery-lab/index.html)

**Question:** *Does suggesting a suitable in-stock replacement during a stockout help more shoppers complete checkout?*

- **System:** Interactive **Three.js 3D supermarket** hosting 12 matched A/B shoppers with isolated per-trip inventory on **FastAPI + SQLite**, local **Ollama (`qwen2.5:1.5b`)**, deterministic shopping tools, and an independent checkout validator (budget, stock, and missing dietary metadata).
- **Prompt Eval (`n = 100`, local `qwen2.5:1.5b`):** Structured schema constraints lifted exact full match from **2/100 → 21/100** (**0/100** budget/quantity errors) while exposing dietary synonym drift that proves why deterministic Python guardrails are essential.
- **Simulated A/B Test (`n = 300` matched pairs, SQL failure tracing):** Lifted simulated valid checkouts from **42.3% → 59.0%** (**+16.7 pp**, 95% CI `[+11.5, +21.8] pp`, holding at **+7.0 pp** under high brand loyalty and **+19.3 pp** under high impatience).
- **Links:** [**Code**](https://github.com/Firasyazidi/ai-grocery-lab) · [**Interactive 3D Replay**](https://firasyazidi.github.io/demos/ai-grocery-lab/index.html) · [**Watch 20s Video**](https://firasyazidi.github.io/demos/ai-grocery-lab/video.html)
